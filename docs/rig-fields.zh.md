# 绑定字段

> 本文档的英文原版见 [rig-fields.md](rig-fields.md)（英文版本为准）。

清单、构建图像及随 `rig.json` 附带的元数据见[虚拟形象文件与文件夹格式](format.zh.md)。

版本 1 使用原始 `source.png` 的坐标系：原点在左上角，x 向右，y 向下。坐标、半径、长度、网格间距和范围带（band）均以**源图像像素**为单位；角度使用**弧度**，而不是姿态滑块所用的角度制。所有数值必须为有限值。椭圆半径和网格单元尺寸必须为正。网格单元尺寸和精细网格矩形坐标必须为整数。饰品框必须是位于图像内的整数矩形。范围带写作 `[start, end]`，且 `start < end`。椭圆是平滑的影响区域，而不是硬性的拆分边界。

只有 `buns`、`strands`、`accessories`、`hand`、`view.gazeCenter` 和 `view.irisTravel` 是可选的。不存在的可选组请省略。必需的区域即使动画幅度很小也必须放置。初始草稿的眼睛多边形为空，在描出它们之前草稿有意处于无效状态。流程见 [agent-guide.zh.md](agent-guide.zh.md)，引擎映射见 [rig-mapping.zh.md](rig-mapping.zh.md)。不要把示例插画的坐标照搬到新图像上。

## 可选衣物

实验性的全身功能；其字段和行为可能会变化。

`cloth` 是可选数组。省略它或使用 `[]` 可保持现有渲染。坐标为源图像像素，x 向右递增，y 向下递增。

| 字段 | 含义 / 默认值 |
| --- | --- |
| `cloth[*].name` | 唯一的字母/数字/下划线/连字符名称；生成 `cloth_<name>.png`。 |
| `cloth[*].outline` | 拆分多边形，至少三个点，包住属于这件衣物的所有荷叶边和飘带。修改后需要重建图层。 |
| `cloth[*].waist` | 上附着折线，至少两个点，从图像左侧到右侧。跟随身体或父级衣物。 |
| `cloth[*].hem` | 下折线，至少两个点，从图像左侧到右侧。覆盖布料全宽，包括外凸的荷叶边。 |
| `cloth[*].seams` | 可选的从腰到下摆的列折线，按图像从左到右排序；为空时使用腰/下摆网格。提供 2–64 条线，每条至少两个点且 y 严格递增。非空 seams 会覆盖 `columns`；长度沿源折线测量。 |
| `cloth[*].tiers` | 可选的 0–8 条横跨各列的接缝折线数组，按腰到下摆排序。每条线至少两个点，且与每列恰好相交一次。有 N 条 tier 时就有 N+1 个耦合链节；为空时使用在源长度一半处分割的两个链节。 |
| `cloth[*].scale` | 可选的正图像比例，每源像素对应的毫米数。省略时，若存在 `legs`，按髋到踝平均长度为 0.8m 推断；否则假定图像高度代表 1.6m。裁剪过或比例特殊的画作请提供此值。 |
| `cloth[*].columns`、`rows` | 整数网格节点数，均至少为 `2`；默认 `8`、`5`。存在 seams/tiers 时，`rows` 是最小值：网格会包含每个 tier 接缝，且每个链节至少两次细分。 |
| `cloth[*].responseGain` | 正的渲染响应夸张倍率；默认 `1`（物理值）。`1.6` 只放大布料角度。子求解器使用未夸张的父级网格，而可见附着跟随夸张后的网格。 |
| `cloth[*].tierGain` | 正的仅渲染倍率，作用于每个链节相对最上链节的角度；默认 `1`。仅在 seams 或 tiers 非空时生效。改变可见弯曲，但不改变物理状态、频率或子求解器输入。 |
| `cloth[*].highModeDamping` | 高于最低频模态的各模态阻尼比的正倍率；默认 `1`。仅在 seams 或 tiers 非空时生效。低于 `1` 会让高阶模态振荡更久；最低模态保持 `0.25 × damping`。 |
| `cloth[*].swing` | 物理摆频率的正倍率；默认 `1`。值为 `1` 时使用源比例、列长度和重力。 |
| `cloth[*].stiffness` | 正的恢复力倍率；默认 `1`。模态频率按 `swing × √stiffness` 缩放，链节有效长度取源长度的 `0.8` 倍。 |
| `cloth[*].damping` | 正的阻尼倍率；默认 `1`。基础小角度阻尼比为 `0.25 × damping`；值越大越抑制振荡。`highModeDamping` 可在 seams/tiers 求解器中进一步缩放高阶模态。 |
| `cloth[*].follow` | 列刚性，`0..1`；默认 `0.85`。为 `1` 时每个链节完全刚性；更低的值增加最多 10% 的链节内二次弯曲，不引入延迟的行链。 |
| `cloth[*].cohesion` | 对列角度和角速度的整数平滑遍数，`0..8`；默认 `3`。 |
| `cloth[*].wind` | 非负的相干微风强度，占 `max` 的比例；默认 `0.05`，`0` 关闭风。所有列接收相同相位。 |
| `cloth[*].max` | 网格相对身体携带形状位移的正软上限，px；默认 `20`。限制下摆处旋转，并预留最多 10% 给微弱的垂直弹跳。网格外的外插点可以移动更远。 |
| `cloth[*].behind` | 可选布尔值，默认 `false`；为 true 时绘制在裸底图之前。改变深度需要重建重叠的拆分图层。 |
| `cloth[*].parent` | 可选的**更早** cloth 条目名称。其位移后的网格驱动这件衣物的腰部，适合附着在裙子上的后飘带。 |
| `body.hip.shift` | 可选的 `bodyAngleX=10` 时全身水平位移，px。与 `band` 一起提供，使水平运动朝固定双脚方向衰减。 |
| `body.hip.band` | 递增的源 y 范围，身体水平位移在其中衰减到零。没有 `hip` 的现有绑定保持原有变形。 |
| `mesh.clothCell` | 正的整数衣物渲染网格间距，px；默认 `8`。与布料网格节点数无关。 |

没有 seams 或 tiers 时，每列保留原有的两个等长摆链节。非空 seams 或 tiers 使用 N 链节串联摆，链节长度沿每条源列在 tier 交点之间测量。没有显式 seams 时，各列在腰和下摆之间插值。校验会拒绝交叉或翻转的网格单元、短于 1 源像素的列、缺失或重复的 tier 交点，以及未按腰到下摆排序的 tier 交点。相邻交点（包括端点）之间必须至少相隔列长度的 0.001。

各列由附着点的水平加速度驱动，包括骨盆偏转（yaw）带来的运动。重力为 9.80665m/s²，换算为源像素。每个链节使用其源长度 0.8 倍的有效长度，介于均匀刚性条带（2L/3）和末端集中质点（L）之间，近似带荷叶边的下摆。附着点向上的加速度会增大表观重力；源 y 向下，因此实现使用 `g - accelerationY`。角度相对世界坐标下的静止形状，因此骨盆倾斜时布料保持悬挂朝向。各链节的绝对角度用摆质量矩阵、重力和科里奥利力联立求解，端点质量与链节长度成正比。旧版等长双链节求解器对两个小角度模态都使用瑞利阻尼。seams/tiers 求解器使用模态阻尼，把每个小角度模态设为 `0.25 × damping`，并对高于最低模态的部分应用 `highModeDamping`。频率随链节长度变化，而不是手工调整的行数。每个渲染链节保持其长度，链节内的小弯曲由 `follow` 控制。每个链节端点保持与该链节支点的距离；一个独立的弱临界阻尼垂直响应可在垂直加速度期间略微改变它。父级加速度在父级未夸张的物理网格上求值；可见附着跟随其渲染网格。不使用额外的随机采样。

`setClothTuning(name, tuning)` 接受包含上述调优字段的 `Partial<ClothTuning>`。`null` 名称应用于所有衣物；字符串只应用于该名称。更新在下一个模拟步生效，不重置速度、不修改绑定配置、也不重建图层。无效值或未知名称会抛出 `RangeError`。Studio 中的编辑会更新绑定配置，并在保存时一并写入。在 Studio 的 **Cloth** 检查器中，可以添加或删除 seam 和 tier 线、拖动顶点、双击边添加顶点，或 Alt 点击顶点删除。这些运动网格编辑不需要重建图像图层；轮廓（outline）编辑则需要。元素通过 `element.avatar` / `await element.ready` 暴露此方法；React 通过其 ref 暴露同一元素，运行时通过 `onLoad` 暴露。

## 可选站立双腿

实验性的全身功能；其字段和行为可能会变化。

省略 `legs` 可完全保持现有变形。`weightShift` 是 `-1..1` 的可选参数，默认 `0`：负值支撑图像左腿，正值支撑图像右腿。带 `legs` 的绑定，待机重心转移使用五秒周期：每个半周期包含 0.9 秒的五次 S 形过渡和 1.6 秒保持，目标为 `±0.7`。现有的身体弹簧会对其平滑。不带 `legs` 的绑定保留之前的确定性正弦和变形。

| 字段 | 含义 |
| --- | --- |
| `legs.spine` | 可选的稳定比例 `0..1`，默认 `0.7`；上躯干保留 `1 - spine` 的微小反向骨盆倾斜，沿脊柱混合。胸部和头部跟随串联弹簧，而不是刚性平移的躯干。 |
| `legs.bob` | 可选的非负额外骨盆下沉，源像素，默认 `2`；由转移速度驱动，保持期间回到零。包含在固定脚 IK 中。 |
| `legs.twist` | 可选的骨盆偏转上限，度，`0..15`；省略或 `0` 保持现有输出。重心转移驱动偏转，保持期间有少量残余。肩膀按 `spine` 部分反转，头部保持正面，双脚固定。 |
| `legs.pelvis` | 骨骼旋转中心 `[x,y]`，源像素。 |
| `legs.shift` | 完全重心转移时的非负水平位移，px。 |
| `legs.tilt` | 完全转移时的非负骨盆倾斜，弧度；自由侧降低。 |
| `legs.bend` | 非负的内屈尺度，px。自由侧膝盖获得 `bend * weightShift²` 的额外向内偏移；其余屈曲朝向相机。同时设定小的软 IK 沉降尺度。 |
| `legs.band` | 递增的源 y 区间，用于反向旋转；脊柱向胸部混合；肩膀倾斜被部分抵消而非完全取消。 |
| `legs.left`、`legs.right` | 图像侧关节，各含 `hip`、`knee`、`ankle` 源坐标点。要求 band 起点 < hip y < knee y < ankle y。静止时的膝盖位置决定腿的弯曲方向。 |
| `legs.split` | 分隔双腿的折线，y 严格递增。起点放在裆部间隙内：该点以下为硬分割，其上八像素内混合过渡。 |

IK 在 3D 中求解，使用前方极向量，然后投影到画面上。骨长在 3D 中保持不变；投影后的骨骼可能缩短。源膝盖相对髋–踝轴的内偏移随该轴移动，保留画出的静止形状。静止时的前向深度为较短投影骨长度的 5%。平滑的骨盆下沉让双腿始终在可达范围内，避免膝盖突然伸直；请为每张插画校准适度的 shift/tilt 值。中性位时附加变形为零。有 legs 时，`bodyAngleX` 进入同一骨盆/IK 变换，提供时使用 `body.hip.shift`，不再叠加旧版髋部剪切。呼吸和身体侧倾保持原有顺序，在踝部之前的最后 55 px 内衰减到零。位于较高踝部及其以下的顶点完全固定。衣物附着通过常规基础变形器跟随骨盆，保留其原有滞后。

Studio 在 **Legs** 下暴露骨盆和关节控制点、可编辑的分界折线，以及 shift、tilt、bend、band 和可选的 twist 字段。这些编辑重新计算权重，不会把图像图层标记为过期。暂停待机动作以测试 **Weight shift** 滑块，然后保存绑定配置以持久化几何和调优。

`render-poses` 在存在 `legs` 时会增加 `±0.6` 的 `weight-left`、`weight-right`，以及覆盖一个五秒周期的 `weight-shift-0..9`。

对于站立绑定，胸部驱动比骨盆滞后约 0.1–0.2 秒；头部稳定再晚一个弹簧，并保留有意的头部动作。独立的待机身体噪声降低到 35%，且不改变随机数消耗。


## 可选下垂手臂

实验性的全身功能；其字段和行为可能会变化。

对正面、与身体之间有透明间隙的下垂手臂使用 `arms`。手臂贴着或位于躯干前方、双手叉腰、交叉手臂以及半身像请省略。这只是对原画的小幅变形；不会重建被遮挡的皮肤或衣物、不会抬起手臂，也不处理布料碰撞。没有 `arms` 时，虚拟形象保持现有变形。原生运行时目前忽略 `arms` 及其参数；此功能请使用 WebGL 运行时。

| 字段 | 含义 |
| --- | --- |
| `arms.left`、`arms.right` | 图像左侧和右侧手臂。各有源像素点 `shoulder`、`elbow`、`wrist` 及各自的 `split` 折线。所有点必须在图像内，且 shoulder y < elbow y < wrist y。 |
| `arms.left.shoulder`、`arms.right.shoulder` | 上臂支点 `[x,y]`，位于袖内靠近腋下。运动在肩膀处衰减到零，保持袖子连接。 |
| `arms.left.elbow`、`arms.right.elbow` | 肘部支点 `[x,y]`。上臂和前臂运动围绕此关节混合。 |
| `arms.left.wrist`、`arms.right.wrist` | 手腕 `[x,y]`；手跟随前臂。 |
| `arms.left.split`、`arms.right.split` | 至少两个源坐标点，y 严格递增，沿透明间隙从腋下正下方描到指尖以下。左侧分界线必须在其肘和腕的右侧；右侧分界线必须在其左侧。有衣物拆分时，也要检查实际的 `base_cloth.png` 间隙。让线避开可见的手臂像素，并为狭窄间隙周围的网格单元留出空间。 |
| `arms.swing` | 可选的上臂旋转上限，度，`0..10`，默认 `4`。 |
| `arms.bend` | 可选的额外屈肘上限，度，`0..12`，默认 `6`。不允许负屈曲。 |
| `arms.inward` | 可选的朝身体方向允许的摆动上限比例，`0..1`，默认 `0.4`。 |

新参数均默认 `0`：`armSwingL` / `armSwingR`（`-1..1`，正值向外）和 `elbowBendL` / `elbowBendR`（`0..1`）。L/R 指图像侧。现有的 `armAngle` / `handAngle` 参数仍控制独立的托腮手部绑定。手臂参数为零时附加变形恰好为零。待机时，手臂以阻尼延迟部分抵消躯干倾斜，并带有小幅呼吸运动。

在 Studio 中，**Body → Arms** 暴露两条关节链、可编辑的分界线和调优。关节、分界线和调优编辑重新计算权重，不需要重建图像图层。四个手臂姿态滑块仅在设置了 `arms` 时出现。**Full-body support** 会列出 Legs / Arms / Cloth 是否已设置；未设置的部位保持标准动作。

Live 会显示已加载虚拟形象支持的身体部位。**Track body movement** 相对校准姿态跟随可见的肘部和手腕。镜像会交换其图像侧。肘部被遮挡时释放该侧；手腕被遮挡时只释放屈肘：保持最后姿态 500 ms，然后以 200 ms 时间常数淡出到待机。正常灵敏度下，额外 90 度屈肘约映射到 `0.6`，相机追踪上限为 `0.75`。追踪使用图像平面角度，因此纯深度方向的运动可能不会产生相同响应。请在手臂放松且可见时校准。

`render-poses` 在存在 `arms` 时会增加 `arms-out`、`arms-in`、`elbows-bent`、`arm-left`、`arm-right`、`arms-body-left`、`arms-body-right`、`arm-cycle-0..9` 和 `arm-idle-0..10`。逐帧检查袖子、肘部、手腕和裙边。手伸进衣物时调低 `swing`、`bend` 或 `inward`；拆分衣物中的分割残留必须在画作中修正，而不是靠增大动作幅度。
