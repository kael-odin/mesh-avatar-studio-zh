# 变形与动作指标

> 本文档的英文原版见 [quality.md](quality.md)（英文版本为准）。

在 `npm ci` 之后，用 Node.js 22.17+ 在本地运行：

```sh
npm run quality -- samples/miko-qipao
npm run quality -- projects/example --seconds 60 --seed 173 --out work/quality/example
```

该命令无需浏览器即可运行，写出 `report.json` 并在控制台输出汇总表。默认输出目录为 `work/quality/<folder-name>/`，不纳入版本控制。项目和输出路径必须位于仓库内；输出不能覆盖输入项目，也不能覆盖 `projects/`、`samples/` 或 `reference/` 下的任何内容。不会上传任何数据。只需要 `rig.json`。缺少已构建图片时会产生提示并跳过受影响的图层网格；不完整的差分图片集会整体跳过，与运行时的回退行为一致。没有头发蒙版时，整图网格在所有位置都使用几何发束影响；这些结果与使用实际蒙版的运行结果不能直接比较。

## 静态变形

报告包含姿态审查集、笑眼和元音嘴型，以及头部 X ±30°、Y ±15°、倾斜 ±15° 与身体倾斜 ±10° 的全部 16 种组合（张嘴、闭眼）。每个姿态都在零物理效果和固定头发／发髻偏移下运行。流苏关节角度固定为 ±0.18 和 ∓0.30 弧度，左右交替。这些是压力测试姿态，不是从动画中采样的帧。

一个不透明的 7 px 三角化网格覆盖整张图片，包括透明区域。有已构建图片时，按绑定中的网格密度提供运行时经过 alpha 过滤的图层网格。底图、手部、眼睑、绘制差分图片和流苏使用各自的运行时变形路径。未激活的差分图片标记为跳过，因为运行时不会放置它们；隐藏的眼睛部件保留指标并标记 `visible: false`。存在差分图片时，分层眼睑保持完全张开，与渲染器一致。测量覆盖 CPU 网格几何；片元着色器裁剪、绘制的嘴型和虹膜移动不在其内。

| 指标 | 含义 |
|---|---|
| `flipped` | 三角形方向反转，或变形后／静止时有符号面积比低于 1e-6 |
| `areaRatio` | 有符号面积比：最小值、第 1 百分位、第 99 百分位和最大值；1 表示面积不变 |
| `anisotropy` | 三角形仿射映射的最大／最小奇异值之比；1 表示各向同性 |
| `stretch` | max(最大奇异值, 最小奇异值的倒数)；1 表示长度不变 |
| `maxDisplacement` | 顶点最大移动量，以原图像素为单位 |
| `worst` | 极端三角形的索引及其在静止坐标下的质心，加上变形后的质心；位移使用顶点位置计算 |

奇异映射在 JSON 中使用字符串 `"Infinity"`。空网格的统计值为 null。退化的静止三角形单独计数，不计入面积／拉伸统计。静态百分位使用最近秩法。控制台的翻转计数对所有测得的姿态／物理组合求和，包括隐藏的眼睛部件，因此不是唯一三角形的数量。

## 时序动作

每个场景都从头开始，使用相同的带种子随机数生成器，以 60 fps 推进 `--seconds` 秒（默认 30，取整到整帧，最少 3 帧）。场景包括：带自动待机动作的待机漫游、按顺序播放的每个动作 ID、固定循环的假名句子，以及六个情绪标签。自动反应播放被禁用；只有待机场景启用自动待机动作。动作 ID 获得相等的时间片，因此较短的运行会截断较长的片段。`schedule` 记录每次开始以及片段是否被截断；`cut` 表示被下一个事件打断，`truncated` 还包括模拟在片段播完前结束的情况。想让每个片段完整播放，请把时长增加到至少"ID 数量 × 最长片段时长"。每个场景结束后恢复随机数状态。

- 参数 `p99`/`max` 测量每帧绝对二阶差分（即所要求的抖动指标，不是三阶时间导数）；反向变化忽略 ≤1e-8 的变化。
- 顶点抖动是 7 px 网格上以像素/帧² 为单位的欧几里得二阶差分。区域互不重叠：头发为发束权重 ≥0.02 的顶点，头部为其余顶点中头部权重 ≥0.5 的顶点，身体包含剩余顶点。位置使用运行时的 Float32 网格缓冲区。P99 使用有界内存的对数分箱，在高于 1e-12 px 时相对高估不超过 0.1%；max 为精确值。空区域报告 null。`vertexJitterExcludingEvents` 还会排除以每个计划开始时刻为中心 ±3 帧内的样本。`eventExclusion` 给出半径和保留／排除的帧数；`vertexJitter` 保留原始测量。对比两者可以识别场景切换带来的伪影。±3 帧的排除并不能消除切换后更长的稳定过程。
- 头发报告相邻刘海发梢间距相对静止状态的最大增量、相对静止间距的最大比值，以及相对每束头发配置的 `max` 的最大物理末端偏移。刘海相邻关系按绑定中的顺序确定。发梢间距包含头部／身体变换；偏移比值使用这些变换之前的物理偏移。
- 流苏报告每个关节的最小值、最大值、范围（弧度）以及每秒反向次数。

对比时请使用相同的绑定、图片、时长和种子。JSON 省略时间戳和绝对路径，因此相同的输入和种子会产生逐字节一致的报告。这些数字用于定位变形和突兀动作；它们不评判画作或动画的观赏性。启动瞬态、眨眼和有意的表情变化都包含在内。

## 默认动作兼容性

`tests/motion-trace.test.ts` 对四个带种子的 20 秒场景每秒及最后一帧采样当前参数和物理状态，舍入到 1e-6。该夹具只需要示例绑定，不需要其图片。参数、发髻、发束和流苏按名称作为键。已有的夹具参数必须与舍入后的轨迹完全一致；物理状态的差异最多为 1e-6。新键会被记录并允许存在，不削弱对已有键的对比。只有在审查过有意的基线变更后才重新生成：

```sh
UPDATE_MOTION_TRACE=1 npx vitest run tests/motion-trace.test.ts
```
